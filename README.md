# Kanhaiya Lal Chaurasiya — Personal Website

Source of my academic website: **https://ckanhaiya.github.io**

I am a PhD candidate at the [Dynamics, Data and Design (D<sup>3</sup>) Lab](https://d3lab-iisc.github.io/), IISc Bengaluru, working on data-driven mechanics, inverse material characterization, and shape memory alloy actuators.

## Build

- Built with [Hugo](https://gohugo.io/) (extended, **v0.119.0**) and the Wowchemy v5 Academic theme.
- Every push to `main` is built and deployed to GitHub Pages by [`.github/workflows/publish.yaml`](.github/workflows/publish.yaml).
- Local preview: `hugo server` (requires Hugo extended 0.119.x and Go).
